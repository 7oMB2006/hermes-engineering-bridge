# 自动执行与审批风险

Hermes x DFSC 提供工程协作，不提供安全沙箱或可靠的人类审核替代品。
请先在不含凭据和重要文件的专用练习目录测试，再决定是否扩大授权。

## 两条不同的执行路径

- **DFSC「代我批准」**：常规命令和文件写入由 DFSC 原生策略自动执行，
  不是每次先让 Hermes 检查。
- **Hermes 审批委托**：只有你在本机明确委托的剩余请求，才由 Hermes 结合目标审阅。
  模型仍可能误判，或受工程文件、工具输出中的恶意指令影响。唤醒不是延时无条件放行。

误批准可能造成文件误改、删除、执行错误命令，或通过命令影响项目目录以外的资源。
目录授权仅限制任务路由，不是操作系统文件沙箱；自动检测也不能保证识别所有危险操作。
「高风险工具操作」允许 Agent 审阅这类请求；「提问与回答」允许它替你作工程选择，
不是转发通知。两项默认不选，不确定时交给真人。

## 长期授权

长期策略按此 Agent 与此项目用于后续新任务，并跨正常重启保留。
1 / 7 / 30 天会到期；「直到手动撤销」不会自动到期。
风险确认不等于授权，也不会代你扩大目录、权限档位或审批类型。

支持风险确认接口的 DFSC 会在授权前展示插件风险及本次实际范围。
「记住」默认不选，仅对当前插件包、风险内容、身份凭据和完全相同的授权范围有效。
包或风险内容变化、凭据变化，或有效期、类型、项目等范围变化时需重新确认。
记住风险不会自动批准之后的权限变更。

## 停止和撤销

- 在 DFSC 对应原生会话停止当前任务；也可要求 Hermes 调用自身任务的 `task.stop`。
- 在「远程访问 → 接入渠道 → 外部 Agent」撤销任务审批委托或长期委托。
- 撤销连接或关闭本机接入，可以阻止后续连接请求。

撤销不能恢复已经修改或删除的数据，也不保证能中止已经启动的所有子进程；
重要工程请使用版本控制和独立备份。撤销审批委托也不是通用进程终止按钮，
需要停止运行时应同时检查原生会话状态。

## 宿主或关联不满足要求

新 companion 的通用模式在派工、续交或代审批前检查风险确认接口与插件关联。
旧宿主缺少接口时报 `host-confirmation-required`；连接未关联本插件时报
`plugin-association-required`，不会静默绕过。查询现有任务和停止入口保留。
安装市场资源本身不能升级宿主或更新 Hermes 已加载的 companion。
