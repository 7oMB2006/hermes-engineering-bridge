# 第一项任务

先完成 [连接准备](SETUP.md)，核对本次连接身份、可见目录，
并按配套说明确认目标 Hermes 已加载 companion。
下面是由你主动发起的真实练习，可能产生对应服务费用。
打开本页本身不会开始执行。

## 准备空目录

新建一个专门的空练习目录，仅在配套宿主中授权它，并回连接页重新检查。
不要使用工作仓库、个人文档或包含凭据的目录。保留计划、工具权限和提问的人工审批。

## 先确认连接模式

新增 `dfsc-external-v1` 目前是源码路径，尚未发布，不能把任意 0.6.0 当成支持。
通用本机模式不依赖飞书；先在「远程访问 → 外部 Agent」完成显式开关、
目录授权，用 `--desktop-connector HOST_CONFIG` 导入非秘密配置，
并由你重载目标独立 profile。
确认工具只提供创建、单轮提交、查询和停止，审批仅在 DFSC 本机处理。

### 通用模式练习

在刚才安装的目标 Hermes profile，主动发送：

> 查询 DFSC 的协议、身份和授权根目录。仅在已授权练习目录中完成一个短任务：
> 新建 HELLO.txt，内容为 Hello from Hermes x DFSC。不要修改其他目录，不联网，
> 不提交或推送。使用一个任务，只派一轮，把读取文件核对内容也写进这一轮要求。
> 提交后告诉我任务 id，不要反复轮询；需要审批时提醒我到 DFSC 处理。

Hermes 应先查询能力，再 `task.create`、`run.submit`。这套协议没有预算和验收 API，
不应索取飞书 grant 或调用 `--pair`、`human.*`、`approval.*`。
用户再询问时才用同一个 taskId 查询，不重复派工来等待结果。

### 旧专版飞书练习

安装资源与只读检查无需飞书，但 companion 0.2.0 的旧专版模式
只从已核验的飞书主人消息取得新工程授权。尚未配置此通道时，先停在连接检查，不承诺其他 Hermes
聊天入口也能派工。按配套说明完成通道和主人身份配置后，再进行这项练习。
将下面的路径替换为实际可见的练习目录：

> 仅在已授权练习目录中完成一个短任务：新建 HELLO.txt，
> 内容为 Hello from Hermes x DFSC。不要修改其他目录，不联网，不提交或推送。
> 完成后读取该文件核对内容，报告实际路径、检查命令和结果，
> 并明确没有验证的事项。开始前复述目录、验收条件和额度。

不附带连接令牌、模型 Key 或渠道凭据。超时或结果不确定时，先查询原委托，
不重复发送同一任务，不换身份重试。

## 核对三个结果

1. **Hermes 接单：** 复述实际目录、目标和任务 id；只有旧专版模式才汇报时长与修正额度。
2. **DFSC 执行：** 对应原生会话真实存在，审批请求可见，
   你可以在本机拒绝或停止，不需要为了继续而开启完全访问。
3. **实际交付：** 练习目录中出现 HELLO.txt，内容正确，
   Hermes 的结论包含实际检查结果和可复核证据。

通用模式只有有界回答摘要，`completed` 不表示测试通过或用户已验收。
需要核对文件、命令输出与测试证据时，由你在 DFSC 原生会话查看；
摘要缺失或截断不能作为通过依据。旧专版才有额外证据查询与验收流程。

只有“成功”消息、任务名称或只读连接通过，都不算跑通。
练习通过后，你得到的是一条已验证的协作链路：委托、桌面执行、人工控制、结果核对。
是否继续授权真实工程，由你另外决定。

## 暂停与结束

通用模式可停止自身任务，或由你在 DFSC 本机停止；关闭入口或撤销连接
只拒绝新请求并尝试撤回未发输入，不自动停止已经开始的原生工作。
重启不重放未完成任务，状态不确定先查原记录。

旧专版通过配套宿主操作原任务。使用已配置飞书通道时，也可在对应会话使用
`/dfsc status`、`/dfsc pause`、`/dfsc stop`；这些命令不是所有渠道的通用能力。
暂停、停止或接管后，以原任务实际状态为准，不新建任务绕过限制。
练习完成后由你决定是否保留文件，本插件不会自动删除目录。
