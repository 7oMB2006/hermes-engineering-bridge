# 第一项任务

仅在 [连接准备](SETUP.md) 全部完成、身份和目录已核对后进行。
这是一个由你主动发起的真实练习，会使用现有 Hermes、模型和 DFSC 环境；
可能产生对应服务费用。打开本页本身不会开始执行。

## 准备一个练习目录

新建一个空的练习目录，并仅在配套宿主中授权该目录。
不要使用工作仓库、个人文档目录或包含凭据的数据目录。
首次练习保留计划、工具权限和提问的人工审批。

## 在飞书向自己的 Hermes 提出委托

将下面的“已授权练习目录”替换为你刚才选定的实际目录：

> 仅在已授权练习目录中完成一个短跑工程：新建 HELLO.txt，
> 内容为 Hello from Hermes。不要修改其他目录，不联网，不提交或推送。
> 完成后读取该文件核对内容，报告实际文件、检查命令和结果，
> 并明确没有验证的事项。开始前复述目录、验收条件和额度。

不要把连接令牌、模型 Key 或飞书凭据一起发送。请求超时或结果不确定时，
先查询原委托状态，不要再次发送同一项任务。

## 看见这三个结果才算跑通

1. **飞书接单。** Hermes 复述本次目录、目标、时长和修正额度。
2. **桌面执行。** 配套宿主显示对应任务及原生会话；有审批时你能看到具体请求，
   可拒绝、暂停或接管，不要求为继续执行而开启完全访问。
3. **真实交付。** 练习目录中出现 HELLO.txt，实际内容正确，
   Hermes 的结论包含本轮检查结果和可复核证据，不只是执行者口头说完成。

只收到一条“成功”消息、只看见任务名称，或只打开了工作台，都不算完成此闭环。

## 你随时可以停止

在对应飞书会话使用 `/dfsc status` 查询当前委托，`/dfsc pause` 暂停，
`/dfsc stop` 结束。桌面接管和审批应在配套宿主中操作。
暂停或停止后的结果以原任务实际状态为准，不新建任务绕过限制。

练习完成后由你检查并决定是否保留练习文件。本插件不会自动删除目录。
