# 排查问题

## 安装后没有 Hermes 图标

先在插件中心确认安装的是 `hermes-engineering-bridge` 资源版本 0.3.0 或更高，
并且当前宿主支持 `agent-bridge-v1` 连接协议。旧宿主可以加载技能和帮助命令，
但不会自动获得新界面。更新市场后还需要更新已安装副本，再刷新插件目录。

没有入口时仍可在插件详情阅读本地指南，或使用 `hermes-bridge-help`。
不要因此删除现有 profile 或应用数据。

## 有工作台，但不知道有没有连接

新客户端默认打开只读「连接」页；未选择 profile 时不会查询 Bridge。
若只有文档或插件详情，先核对客户端是否已包含连接协议适配，不要靠相同版本号猜测。

| 连接页状态 | 下一步 |
| --- | --- |
| Profile 不可用 | 重新选择含 `config.yaml` 的本机 profile，不选源码或资源目录 |
| 缺少 companion 配置 | 按配套说明安装到这个 profile，而不是另一个身份 |
| 连接配置无效 | 管理者核对显式 `bridgeRoot` 与对应的本机描述文件 |
| 缺少配对凭据 | 在配套宿主人工完成此身份配对，不复制别人的凭据 |
| 无法连接 Agent Bridge | 检查配套宿主是否运行、配对是否有效、目录是否仍存在 |
| 连接身份不匹配 | 停止派工，由管理者核对 profile、描述文件与宿主登记 |
| 只读连接已核验但没有目录 | 核对身份授权与 companion 目录范围的交集 |

只读连接成功不证明 companion 已加载、可派工或飞书正常。按
[连接准备](SETUP.md) 重载并逐项核对，不重复创建任务来试探连接。

## 飞书没有响应，或桌面没有任务

先确认目标 Hermes profile 能接收普通飞书消息，再确认 companion 已启用并重载。
随后检查配套宿主接入、身份配对和目录授权。
资源工作台不会替你启动网关，也不会自动修复飞书配置。

## 任务卡住或结果不确定

先查询同一个任务，区分等待审批、人工暂停、人工接管、额度耗尽和连接中断。
查看具体待处理请求，不要为推进任务而批准全部操作。
超时不代表执行失败；恢复连接后查询原单，不重复派发、不换身份重试。

## 更新、停用与卸载

| 你的目的 | 应处理什么 |
| --- | --- |
| 更新指南和工作台入口 | 在插件中心更新资源；旧宿主按说明重装和重载 |
| 忘记本客户端选择的 profile | 连接页点忘记选择；不修改原目录、凭据或任务 |
| 暂停或停止工程 | 在配套宿主或对应飞书会话操作当前任务 |
| 断开整个工程桥 | 在配套宿主关闭接入 |
| 停用某个 Hermes 身份 | 按 Hermes 官方方式停用该 profile 的 companion，并重载 |
| 撤销目录或身份权限 | 由管理者在宿主可信入口核对并调整 |
| 只卸载市场插件 | 只移除资源，不停止任务、不撤销 companion 或宿主权限 |

不要删除整个 profile、任务账本或普通 DFSC 数据来代替卸载。
配套组件的完整升级、回退和移除步骤以项目根目录 `INSTALL.txt` 为准。
