# 排查问题

## 安装后没有 Hermes 图标

先在插件中心确认安装的是 `hermes-engineering-bridge` 资源版本 0.2.0 或更高，
并且当前宿主支持插件桌面入口协议。旧宿主可以加载技能和帮助命令，
但不会自动获得新界面。更新市场后还需要更新已安装副本，再刷新插件目录。

没有入口时仍可在插件详情阅读本地指南，或使用 `hermes-bridge-help`。
不要因此删除现有 profile 或应用数据。

## 有工作台，但不知道有没有连接

当前工作台提供入门文档，不查询真实 Bridge 状态。
显示本页仅证明资源可以读取，不能证明配套宿主、companion、配对或飞书正常。
请管理者按 [连接准备](SETUP.md) 进行只读身份和目录核对。

## 飞书没有响应，或桌面没有任务

先确认目标 Hermes profile 能接收普通飞书消息，再确认 companion 已启用并重载。
随后检查配套宿主接入、身份配对和目录授权。
资源工作台不会替你启动网关，也不会自动修复飞书配置。

## 任务卡住或结果不确定

先查询同一个任务，区分等待审批、人工暂停、人工接管、额度耗尽和连接中断。
查看具体待处理请求，不要为推进任务而批准全部操作。
超时不代表执行失败；恢复连接后查询原单，不重复派发、不换身份重试。

## 更新、停用与卸载

| 你的目的 | 应处理什么 |
| --- | --- |
| 更新指南和工作台入口 | 在插件中心更新资源；旧宿主按说明重装和重载 |
| 暂停或停止工程 | 在配套宿主或对应飞书会话操作当前任务 |
| 断开整个工程桥 | 在配套宿主关闭接入 |
| 停用某个 Hermes 身份 | 按 Hermes 官方方式停用该 profile 的 companion，并重载 |
| 撤销目录或身份权限 | 由管理者在宿主可信入口核对并调整 |
| 只卸载市场插件 | 只移除资源，不停止任务、不撤销 companion 或宿主权限 |

不要删除整个 profile、任务账本或普通 DFSC 数据来代替卸载。
配套组件的完整升级、回退和移除步骤以项目根目录 `INSTALL.txt` 为准。
