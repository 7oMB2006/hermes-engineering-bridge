# 排查问题

## 装了以后没有入口

在插件中心确认实际安装副本是 `hermes-engineering-bridge` 0.3.0 或更高，
并确认客户端构建支持 `agent-bridge-v1` 及对应引导。
DFSC `>=0.6.0` 只是版本下限，同号构建不一定有这些能力。
市场刷新不等于已安装副本更新。

顶栏图标打开的是状态小面板；点击「打开完整工作台」才进入连接页。
旧客户端仍可在插件详情阅读本地指南或使用 `hermes-bridge-help`。
不要为找入口删除 profile 或应用数据。

## 检查没有通过

先确认选中的是目标 Hermes 身份目录，变更组件或配置后再点「重新检查」。
首次打开不自动扫描本机；检查不负责安装、配对、授权或启动服务。

| 本次结果 | 下一步 |
| --- | --- |
| 尚未选择身份目录 | 选择目标 profile，目录应包含 `config.yaml` |
| Profile 不可用 | 重新选择本机已有 profile，不选源码或资源目录 |
| 缺少 companion 配置 | 按 [连接准备](SETUP.md) 安装到这个 profile |
| 连接配置无效 | 核对 `dfsc-bridge/config.json`、显式 `bridgeRoot` 及对应描述文件 |
| 缺少配对凭据 | 由你或管理员在配套宿主完成此身份配对，不复制他人凭据 |
| 无法连接 Agent Bridge | 确认配套宿主正在运行、接入已启用、配对有效、目录仍存在 |
| 连接身份不匹配 | 停止派工，核对 profile、描述文件与宿主登记 |
| 已核验但没有可见目录 | 核对宿主授权与 companion 范围的交集，不扩大到全盘 |
| 检查失败 | 重试并核对安装副本是否刚更新；必要时重新选择 profile |

目录通过只证明目录和标记有效；companion 配置通过只证明配置有效。
只读连接成功不证明 companion 已加载、可以派工或消息渠道正常。
完整页只显示首批任务中符合当前范围的摘要，空列表不等于没有历史任务。

## Hermes 不回复，或 DFSC 没有任务

先确认目标 Hermes 能回复普通消息，再按 `INSTALL.txt` 确认 companion
已在同一 profile 启用并成功重载，最后核对配套宿主接入、身份和授权目录。
连接页不会启动网关或自动修复渠道。

### 新增通用模式

`dfsc-external-v1` 是尚未发布的源码路径，不代表所有 0.6.0 构建都支持。
确认宿主实际存在「远程访问 → 外部 Agent」，显式开关已开启，
连接名称及授权根目录正确。复制的是非秘密 `configPath`，
安装器使用 `--desktop-connector HOST_CONFIG`，不是旧 `--pair`。
目标独立 profile 应明确声明 `protocol=dfsc-external-v1`，并由你成功重载。

若提示已有连接不同，先确认是否选错 profile；不要为继续而盲目追加
`--replace-connection`。确实切换时保留备份、旧 delivery 和旧凭据。
协议或身份不匹配时停止派工，不尝试旧专版人类凭据，也不自动降级。
配对不验证后续消息是否为真人；本机工具审批仍需人处理。

此模式没有飞书依赖、预算、事件唤醒、自动修正或验收 API。
任务提交后 Hermes 不自动回报不等于故障；由你询问时查同一个任务，
不要启动循环轮询。`awaitingLocalApproval` 表示要去 DFSC 本机审批或回答。

### 旧专版模式

没有 protocol 的旧配置保持旧模式。其新委托仍需已核验飞书真人授权；
检查原渠道和主人身份，不把新通用模式的开关当成旧飞书授权。

## 任务卡住或结果不确定

查询同一个任务，区分等待审批、人工暂停、接管、额度耗尽和连接中断。
查看具体待处理请求，不为推进任务批准全部操作。超时不代表执行失败；
恢复连接后查询原单，不重复派发。
人工暂停、接管和额度是旧专版状态。通用模式一任务只派一轮，
没有追加修正 API；不更换 key 或新建任务绕过未知结果。
`completed` 仅说明原生轮次结束，摘要不替代完整工具与测试证据。

## 更新与移除

| 目的 | 操作及边界 |
| --- | --- |
| 更新资源 | 插件中心更新已安装副本，核对版本和来源；旧宿主按其说明重装 |
| 忘记本客户端选择 | 只移除 profile 绑定，不改原目录、配对或任务 |
| 停止通用任务 | 在 DFSC 本机操作，或由已授权适配器停止自身任务 |
| 暂停、接管或飞书命令 | 仅按旧专版支持能力操作当前任务，不是通用接口能力 |
| 断开通用入口 | 在「远程访问 → 外部 Agent」关闭接入，或撤销单连接；已开始工作不会自动终止 |
| 断开旧工程桥 | 在旧专版宿主关闭对应接入 |
| 停用某个 companion | 用 Hermes 可信管理入口停用对应 profile 的插件并重载 |
| 撤销身份或目录权限 | 由你或管理员在宿主可信入口核对并调整 |
| 卸载市场资源 | 只移除资源，不停止任务、不撤销 companion 或宿主权限 |

不要删除整个 profile、任务账本或普通 DFSC 数据代替卸载。
完整安装、升级、回退和移除步骤见项目根目录 `INSTALL.txt`。
