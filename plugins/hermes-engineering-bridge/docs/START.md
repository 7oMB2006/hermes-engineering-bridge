# 开始使用 Hermes

Hermes 可以从飞书接收工程委托，通过 DFSC 执行，在你需要时请求审批，并根据实际
变更和测试结果复核交付。你也可以在桌面查看、暂停或接管同一项工程。

## 这次安装完成了什么

你得到的是 **Hermes 入门资源包**：本地指南、帮助命令和工程证据规范。
支持桌面入口协议的宿主还会显示 Hermes 工作台入口。

安装资源包与连接工程桥是不同的步骤。这个工作台不会读取连接凭据，
也不显示未经查询的“已连接”“已配对”或任务状态。

| 组件 | 负责什么 | 本资源包是否提供 |
| --- | --- | --- |
| DFSC 资源插件 0.2.0 | 入门工作台、帮助和工程证据规范 | 是 |
| DFSC Hermes 0.6.0 配套宿主 | Agent Bridge、原生会话、任务、审批和接管 | 否，须单独取得 |
| Hermes companion 0.2.0 | 把对应 Hermes 身份接到配套宿主 | 否，须单独安装 |
| Hermes、模型与飞书配置 | 接收你的消息并运行负责人 | 否，沿用你自己的环境 |

## 选择下一步

**只有普通 DFSC，或不确定环境是否齐全：**
先阅读 [连接准备](SETUP.md)。缺少配套宿主时，可以先保留资源包，不需要
反复安装，也不要把模型 Key 或飞书凭据填入聊天来“激活”。

**已经取得配套宿主和 companion：**
由你或管理员完成身份配对、目录授权和只读核对，成功后再做
[第一项任务](FIRST_TASK.md)。

**此前用过，今天连不上：**
先看 [排查问题](TROUBLESHOOTING.md)，查询原任务，不要重复发起同一委托。

## 安全起点

第一次只授权一个专门的练习目录。保留原生审批，不开启全盘或永久权限。
这个入口不会自动派工、调用模型、注册飞书或扩大授权范围。
