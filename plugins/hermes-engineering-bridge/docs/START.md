# 开始使用 Hermes x DFSC

Hermes 负责理解你的委托、核对结果；DFSC 在获准的本机目录中执行工程，
保留原生会话、审批和执行证据。你可以在桌面查看和停止任务。

开启自动执行或长期委托前，请先阅读 [自动执行与审批风险](RISKS.md)。
查看状态不会触发授权确认；风险确认也不会自动授予权限。

## 安装后拿到了什么

你得到的是资源插件：本地指南、帮助命令和工程证据规范。
支持 `agent-bridge-v1` 及本轮引导的新客户端还提供连接工作台。
DFSC `>=0.6.0` 是版本下限，版本号达标不证明构建已包含这些能力或 Bridge 服务。

顶栏图标先展开状态小面板，不离开当前聊天；需要配置时点击「打开完整工作台」。
小面板打开或手动刷新时查询，显示本次核验身份与首批最多 5 项任务，
不是实时在线状态。再次点击图标、Escape 或点击外部可收起。

安装资源包与连接工程桥是不同的步骤。首次打开不会自动寻找 profile 或连接凭据，
不会安装 Hermes、启动服务、配对、授权或创建任务。

## 先准备，再检查

完整协作另需三项：你自己的 **Hermes Agent**、本项目维护的
**Hermes x DFSC companion**、实际实现所选连接协议的 **DFSC 宿主**。
companion 不是 Hermes 官方提供的桥。安装资源与只读检查无需飞书；
先区分下面两种模式，不要混用配对步骤。

### 通用本机模式：新增源码路径，尚未发布

需要明确提供 `dfsc-external-v1` 和插件风险确认接口的 DFSC 构建及本仓库新增的 companion 适配。
不是任意 0.6.0 安装包都支持。此模式不依赖飞书：

1. 在 DFSC「远程访问 → 外部 Agent」显式打开本机接入，填写名称，
   只选此次允许使用的项目根目录，关联已安装的 `Hermes x DFSC` 插件，确认授权。
   已有普通连接可在没有进行中的任务或长期策略时使用「关联插件」。
2. 复制该连接的非秘密 `config.json` 路径，用已有 Hermes 环境将 companion
   安装到独立 profile：`--desktop-connector HOST_CONFIG`，不要使用旧 `--pair`。
3. 保留安装备份，再由你按 Hermes 可信入口启用、重载目标 profile。
   安装器不重载网关；已装另一模式的 profile 不会被静默覆盖。

配对允许持有凭据的本机进程创建任务，不证明它之后收到的聊天来自真人。
一任务只派一轮，审批默认在 DFSC 本机处理；你可显式委托所选类型，
或为此身份与项目设置长期策略。支持的 Hermes 会话可收到审批唤醒，
但仍由模型独立审阅，不是延时放行。不提供预算或自动验收 API。

### 旧 DFSC Hermes 专版模式

继续使用配套 Bridge 宿主和原有独立配对。当前 companion 0.2.0 的旧模式
新工程授权仍使用已配置、核验过的飞书通道，不表示其他入口也能取得该授权。
没有显式 protocol 的旧配置保持旧模式，不会因连接失败自动改用通用模式。

### 两种模式的只读检查

1. 打开完整工作台，在「连接」页选择你要使用的 Hermes 身份目录（profile），
   不是源码目录或市场资源目录。
2. 点「重新检查」，按身份目录、companion 配置、Bridge 配对连接、授权目录四项，
   看本次检查到了什么、下一步处理什么。缺项时进入对应指南，不需要反复装资源。
3. 由你或管理员按 [连接准备](SETUP.md) 选择对应模式，补齐组件、配对和授权，
   再回到连接页检查。
4. 确认目标 Hermes 已加载 companion 后，由你主动发起 [第一项任务](FIRST_TASK.md)。

页面只接收身份、可见目录和任务摘要，不接收令牌。
检查不读取 `config.yaml` 内容、`human.json` 或 `.env`，
不搜索其他身份，不代替你修改配对或权限。

## 看到通过意味着什么

身份目录通过，只说明所选目录及 profile 标记有效，不证明 Hermes 正在运行。
companion 配置通过，只说明配置有效，不证明 companion 已加载。
「只读连接已核验」只证明本次身份、目录和摘要查询成功，不证明可以派工。
第一次练习有真实交付后，才记为链路跑通。
通用模式的 `completed` 只表示原生轮次结束，不表示测试通过或用户已验收。

「忘记此选择」只移除当前客户端的 profile 绑定，不解除配对、不撤销授权。
资源更新后需重新选择 profile；同一安装的客户端重启可保留选择。
没有入口、连接异常或任务状态不确定时，看 [排查问题](TROUBLESHOOTING.md)。
