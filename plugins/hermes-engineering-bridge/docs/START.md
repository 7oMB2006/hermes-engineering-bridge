# 开始使用 Hermes

Hermes 可以从飞书接收工程委托，通过 DFSC 执行，在你需要时请求审批，并根据实际
变更和测试结果复核交付。你也可以在桌面查看、暂停或接管同一项工程。

## 这次安装完成了什么

你得到的是 **Hermes 资源包**：本地指南、帮助命令和工程证据规范。
支持 `agent-bridge-v1` 连接协议的新客户端还会显示 Hermes 主视图和只读连接页。
顶栏图标先展开轻量 Agent 状态面板，不离开当前聊天。需要配置或查看完整目录与任务时，
点击「打开完整工作台」。再次点击图标、Escape 或点击外部可收起小面板。
小面板展示本次检查的身份与首批最多 5 项任务，打开或手动刷新时更新，不是实时在线状态。

安装资源包与连接工程桥是不同的步骤。首次打开不会自动寻找 profile 或连接凭据。
你主动选择本机 profile 后，宿主读取该身份的 `model.json` 凭据核验连接，
页面只接收身份、可见目录和任务摘要，不接收令牌。不会读取 `human.json` 或 `.env`。

| 组件 | 负责什么 | 本资源包是否提供 |
| --- | --- | --- |
| DFSC 资源插件 0.3.0 | 连接页声明、指南、帮助和工程证据规范 | 是 |
| 支持连接协议的新 DFSC 客户端 | 绘制只读面板、选择 profile、核验连接 | 否，需要对应宿主构建 |
| DFSC Hermes 0.6.0 配套宿主 | Agent Bridge、原生会话、任务、审批和接管 | 否，须单独取得 |
| Hermes companion 0.2.0 | 把对应 Hermes 身份接到配套宿主 | 否，须单独安装 |
| Hermes、模型与飞书配置 | 接收你的消息并运行负责人 | 否，沿用你自己的环境 |

## 选择下一步

**只有普通 DFSC，或不确定环境是否齐全：**
先阅读 [连接准备](SETUP.md)。缺少配套宿主时，可以先保留资源包，不需要
反复安装，也不要把模型 Key 或飞书凭据填入聊天来“激活”。

**已经取得配套宿主和 companion：**
由你或管理员完成身份配对、目录授权。在「连接」页选择已安装 companion 的
Hermes profile 目录，核对身份、可见目录和任务摘要。
「只读连接已核验」不证明 companion 已加载，也不证明可以派工；按配套说明
重载并检查实际链路后，再做
[第一项任务](FIRST_TASK.md)。

**此前用过，今天连不上：**
先看 [排查问题](TROUBLESHOOTING.md)，查询原任务，不要重复发起同一委托。

## 安全起点

第一次只授权一个专门的练习目录。保留原生审批，不开启全盘或永久权限。
这个入口不会自动派工、调用模型、注册飞书或扩大授权范围。
「忘记此选择」只移除当前客户端保存的 profile 绑定，不解除配对、不撤销授权。
资源更新后需重新选择 profile；同一安装的客户端重启可保留选择。
