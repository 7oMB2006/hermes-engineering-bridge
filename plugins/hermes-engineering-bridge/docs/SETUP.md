# 连接准备

## 先核对四个条件

1. **宿主有 Agent Bridge。** 普通 DFSC 的插件按钮区只是界面扩展能力。
   Hermes 入门工作台出现，不表示当前宿主已经有工程桥。
2. **Hermes 已能接收你的飞书消息。** 使用自己的账号、模型和独立 profile。
   资源插件不会替你注册飞书应用或配置 Hermes。
3. **取得 companion 0.2.0 与安装说明。** companion 不在市场资源目录里；
   配套宿主安装器也不包含在此插件内。
4. **明确授权范围。** 每个智能体使用独立身份和 profile，先选一个练习目录，
   不共享其他智能体的连接描述符，不扩大已有项目权限。

任一条件不满足时先停在这里。重复安装资源、复制插件目录或要求模型自行寻找凭据，
都不能补齐这些前置组件。

## 获取配套组件

[Hermes 工程桥项目](https://github.com/7oMB2006/hermes-engineering-bridge) 当前需要访问权限。
无法打开时，向维护者索取受支持宿主、companion 和对应安装说明；
不能把“仓库打不开”当作你操作失败，也不要使用不明来源的替代包。

取得项目后，由管理者阅读根目录 `INSTALL.txt` 和 `companion/README.md`：

1. 安装并打开配套宿主，在工程面板启用接入、授权实际目录。
2. 用 Hermes 自己的 Python 环境运行 companion 安装器，指定目标 profile。
3. 人工核对身份和目录后完成配对。安装器会报告备份及是否需要重载。
4. 使用 Hermes 官方入口重载对应 profile；安装成功不等于插件已加载。

本页不提供一键安装、配对或授权按钮。管理操作应由你或管理员在可信入口完成，
不能交给工程会话中的模型代办。

## 只读确认后再派工

在支持 `agent-bridge-v1` 的新客户端中，打开 Hermes 主视图的「连接」页：

1. 选择已安装 companion 的本机 Hermes profile 目录，不是源码目录或市场资源目录。
   该目录须有 `config.yaml` 与 `dfsc-bridge/config.json`，配置须明确包含 `bridgeRoot`。
2. 核对连接身份与可见目录。宿主只读取对应身份的 `model.json`，
   不要求粘贴 token，也不读取 `human.json`、`.env` 或 `config.yaml` 内容。
3. 查看首批任务摘要。面板只读，最多展示首批 50 条中符合身份和目录范围的 20 条，
   不包含对话、工具输出或审批操作。空列表不证明全部历史没有任务。
4. 更改配套配置或启动服务后，点重新检查。忘记选择不修改原 profile 或配对文件。

当前桌面主线不内置 Agent Bridge 服务。缺少配套宿主时，连接页不能代替安装，
也没有一键启用、配对或授权按钮。普通 DFSC 的 `0.6.0` 版本号不能证明已包含新协议。
旧客户端可能不显示工作台，请在插件详情阅读指南，并由管理者按配套说明
在目标 profile 的管理终端查询 `system.capabilities` 和 `task.list`。

读不到或信息不符时，先排查宿主接入、配对和重载。不要把安装完成、
只读查询成功或资源工作台打开，当作 companion 已加载或真实飞书链路已通过验收。

条件齐全后，继续 [第一项任务](FIRST_TASK.md)。
