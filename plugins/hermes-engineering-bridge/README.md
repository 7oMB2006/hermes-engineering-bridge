# Hermes 工程桥

资源版本 **0.2.0**。从 [开始使用](docs/START.md) 了解安装后能做什么。

支持插件桌面入口协议的 DFSC 宿主，会在顶栏插件区域显示 Hermes 图标。
点击进入主视图工作台，查看连接准备、第一项任务和排查步骤。旧宿主仍可加载
帮助命令、技能和本地文档，但不会因为安装本插件而获得新界面。

本插件提供入门资源，不包含可执行前端脚本、MCP 调度服务、宿主安装器或
Hermes/Python 环境。**工作台入口出现不表示工程桥已连接。**
完整派工仍需 DFSC Hermes 0.6.0 的 Agent Bridge、Hermes companion 0.2.0，
以及独立身份、目录授权和配对。

## 本地指南

- [开始使用](docs/START.md)：组件分工与下一步。
- [连接准备](docs/SETUP.md)：核对前置条件、权限及获取途径。
- [第一项任务](docs/FIRST_TASK.md)：从无破坏性的练习开始。
- [排查问题](docs/TROUBLESHOOTING.md)：入口、连接、审批及卸载。
- [更新记录](CHANGELOG.md)。

`hermes-bridge-help` 只提供帮助；`hermes-engineering-evidence` 规范工程执行证据。
两者都不会自动配对、修改权限或创建任务。

## 配套安装与更新

项目根目录的 `INSTALL.txt` 和 `companion/README.md` 是管理者的配套安装指南，
不是本资源包内的安装器。配套项目当前需要访问权限；尚未取得受支持宿主或
companion 时，请先联系维护者，不要从不明来源寻找安装包。

更新资源前核对版本与来源。支持更新操作的宿主使用插件中心的更新入口；
旧宿主按其说明卸载旧资源、重新安装并重载会话。市场刷新不等于安装副本已更新。
资源卸载不停止已有工程，也不撤销 companion 或宿主权限。
