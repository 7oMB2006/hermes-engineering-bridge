# Hermes 工程桥

资源版本 **0.3.0**。从 [开始使用](docs/START.md) 了解安装后能做什么。

支持 `agent-bridge-v1` 的新 DFSC 客户端，会在顶栏插件区域显示 Hermes 图标。
点击先展开轻量 Agent 状态面板，不切换当前聊天；再次点击、Escape 或点击外部收起。
从「打开完整工作台」进入连接页，主动选择本机 profile 后核验只读连接、身份、
目录和任务摘要。小面板只显示本次检查的身份与首批最多 5 项任务，打开或手动刷新时更新，
不将摘要当作实时在线状态。
同时保留连接准备、第一项任务和排查指南。旧宿主仍可加载
帮助命令、技能和本地文档，但不会因为安装本插件而获得新界面。

本插件提供入门资源，不包含可执行前端脚本、MCP 调度服务、宿主安装器或
Hermes/Python 环境。**工作台入口出现不表示工程桥已连接。**
只读核验成功也不代表 companion 已加载、可派工或真实飞书链路正常。
完整派工仍需 DFSC Hermes 0.6.0 的 Agent Bridge、Hermes companion 0.2.0，
以及独立身份、目录授权和配对。

## 配套安装与更新

项目根目录的 `INSTALL.txt` 和 `companion/README.md` 是管理者的配套安装指南，
不是本资源包内的安装器。配套项目当前需要访问权限；尚未取得受支持宿主或
companion 时，请先联系维护者，不要从不明来源寻找安装包。

更新资源前核对版本与来源。支持更新操作的宿主使用插件中心的更新入口；
旧宿主按其说明卸载旧资源、重新安装并重载会话。市场刷新不等于安装副本已更新。
资源卸载不停止已有工程，也不撤销 companion 或宿主权限。
