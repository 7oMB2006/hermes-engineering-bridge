# 更新记录

## 0.3.0 - 2026-11-09

- 声明固定 `agent-bridge-v1` 只读连接页，需包含此协议适配的新 DFSC 客户端。
- 用户主动选择本机 profile 后，由宿主读取配对凭据并核验身份、可见目录和首批任务摘要；凭据不进入页面。
- 缺少配置、配对、配套服务或身份不符时显示各自诊断；保留四页安装与排错指南。
- 连接核验不代表 companion 已加载或可以派工；当前桌面主线不内置配套 Agent Bridge 服务。
- 不修改 companion 0.2.0 的运行逻辑，不增加自动配对、授权、任务控制或模型请求。
- 保留已确认的头像与 17px 明暗主题直角图标原始字节。旧宿主保留插件详情指南入口。

## 0.2.0 - 2026-11-09

- 新增声明式 Hermes 主视图入口；详情页保留角色头像，桌面入口使用随明暗主题切换的 17px 直角图标。
- 随包提供开始使用、连接准备、第一项任务和排查问题四页本地指南。
- 明确区分资源安装、宿主支持、companion 配对和真实业务验收。
- 帮助命令改为按使用阶段引导，不推测连接或任务状态。
- 不修改 companion 运行逻辑，不增加自动安装、派工、网络请求或授权行为。
- 新入口需要支持插件桌面入口协议的 DFSC；旧宿主继续提供原有资源。
