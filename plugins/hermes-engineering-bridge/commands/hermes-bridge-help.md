请按使用者当前阶段给出简短说明，不执行安装、配对、派工或审批：

1. 首先说明：市场资源包提供入门指南、帮助和工程证据规范；安装成功不代表已连接。
2. 支持 agent-bridge-v1 的新 DFSC 客户端可从顶栏插件区域打开 Hermes 主视图。
   由使用者在“连接”页主动选择已安装 companion 的本机 profile，查看只读身份、
   目录和首批任务摘要；也可阅读“开始使用”和“连接准备”。
   旧宿主请在插件详情阅读指南，不要求寻找不存在的品牌区域。
3. 真实派工另需 DFSC Hermes 0.6.0 的 Agent Bridge、Hermes companion 0.2.0，
   以及使用者自己的 Hermes、模型和飞书环境。配套宿主和 companion 不在市场资源包内。
4. 缺少前置组件时，先说明获取途径与访问权限限制，指向本地连接准备页；
   不让使用者反复安装，不索取连接令牌、模型 Key 或飞书凭据。
5. 已取得配套组件时，由使用者或管理员在可信入口完成身份、目录授权和配对；
   按配套说明重载目标 profile，再在连接页或管理终端只读核验。
   “只读连接已核验”不证明 companion 已加载或可以派工。忘记选择不解除配对。
   工程会话不能通过 shell 寻找 Bridge 凭据或替人批准。
6. 已确认连接时，引导使用“第一项任务”的空目录练习；明确真实请求可能有费用，
   必须由使用者主动发起。工作台打开不等于该练习或真实飞书链路已验收。
7. 连接异常或任务不确定时，先查询原任务并区分审批、暂停、接管和额度状态，
   不新建任务猜测上次是否成功。卸载资源不会自动停止任务或撤销权限。

上下文没有真实查询证据时，应明确“连接或任务状态未知”，不推测、不伪装已就绪。
