description: 说明 Hermes x DFSC 安装后得到什么、连接缺项和第一项任务。
---

按使用者当前阶段给出简短说明，不执行安装、配对、派工或审批：

1. 品牌是 Hermes x DFSC。市场安装得到指南、帮助和工程证据规范；
   安装成功不表示 Hermes 已安装、桥已连接或可以派工。
2. 支持 agent-bridge-v1 及本轮引导的新客户端，顶栏图标先开状态小面板，
   不切换当前聊天；点击“打开完整工作台”才进入主视图。
   由使用者主动选择 Hermes 身份目录（profile），再检查身份目录、
   companion 配置、Bridge 配对连接和授权目录。首次打开不自动搜索 profile。
3. 真实协作另需 Hermes Agent、模型、本项目维护的 companion 及实际支持所选协议的
   DFSC 宿主。companion 不是 Hermes 官方组件。安装资源与只读检查无需飞书。
   DFSC >=0.6.0 仅为版本下限，不证明构建有协议或 Bridge 服务。
   新增 dfsc-external-v1 是源码路径，尚未发布，不是所有 0.6.0 都支持。
   使用者在“远程访问 → 外部 Agent”显式开启、选择授权根目录并确认连接，
   复制非秘密 configPath，用 --desktop-connector HOST_CONFIG 安装到独立 profile，
   由使用者启用和重载。此模式不依赖飞书，一任务一轮，审批仅在 DFSC 本机处理。
   旧 DFSC Hermes 专版仍使用原配对、--pair 和逐委托飞书真人授权；
   旧配置缺省保持旧模式，不因故障自动降级，不混用两套凭据。
4. 缺项时指向本地“连接准备”和公开项目仓库，不让使用者反复安装资源，
   不虚构宿主安装包或一键配对，不索取令牌、模型 Key 或渠道凭据。
   可以解释非秘密配置和步骤，身份配对及目录授权由使用者或管理员在可信入口确认。
5. 目录有效不证明 Hermes 正在运行；companion 配置有效不证明已启用或加载；
   只读连接已核验只证明本次身份、目录与摘要查询成功，不证明可以派工。
   按配套说明启用并重载目标 profile 后，再核对真实链路。
   工程会话不能通过 shell 搜索 Bridge 凭据或替人批准。
6. 通用模式的本机配对不验证后续聊天是否来自真人，不提供 human.*、审批代理、
   预算、事件唤醒或验收 API。已有其他连接的 profile 不静默覆盖；
   只有使用者确认切换时才使用 --replace-connection，并保留备份与旧投递状态。
   条件齐全后，引导使用“第一项任务”的空目录练习，明确由使用者主动发起、
   可能产生服务费用，并以实际文件、原生执行和检查证据判断是否通过。
   completed 只代表原生轮次结束；通用摘要不是完整测试证据，不虚报验收通过。
7. 状态不确定时查询原任务，不循环轮询或重复创建任务猜测结果。
   暂停、接管、预算及飞书命令是旧专版能力，不向通用模式承诺。
   忘记选择只移除客户端绑定；卸载资源不停止任务或撤销其他组件权限。

没有真实检查证据时，明确“连接或任务状态未知”，不推测、不伪装就绪。
